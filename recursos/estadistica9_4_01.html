4.1 Clasificar variables cuantitativas en discretas o continuas

Explicación

En estadística, una variable es una característica que puede variar de un individuo a otro. Cuando dicha característica se expresa mediante números, se denomina variable cuantitativa.

Las variables cuantitativas se clasifican en:

  • Variables cuantitativas discretas.
  • Variables cuantitativas continuas.

Variables cuantitativas discretas

Son las que se obtienen mediante un conteo. Sus valores suelen ser números enteros y no admiten valores intermedios entre dos resultados consecutivos.

Ejemplos:

  • Número de estudiantes en un aula.
  • Cantidad de hermanos.
  • Número de vehículos en un parqueo.
  • Cantidad de libros en una biblioteca.

Variables cuantitativas continuas

Son las que se obtienen mediante una medición. Pueden tomar cualquier valor dentro de un intervalo determinado y generalmente admiten decimales.

Ejemplos:

  • Estatura de una persona.
  • Peso corporal.
  • Temperatura ambiental.
  • Tiempo empleado para realizar una actividad.

Resumen

Variable Discreta Variable Continua
Se obtiene contando. Se obtiene midiendo.
Toma valores separados. Puede tomar infinitos valores.
Generalmente usa números enteros. Puede incluir decimales.
Ejemplo: número de hijos. Ejemplo: estatura.

Ejemplo

Clasifique las siguientes variables cuantitativas:

  1. Número de estudiantes en un colegio.
  2. Peso de una mochila.
  3. Cantidad de mascotas en una familia.
  4. Temperatura de una habitación.

Solución:

Variable Clasificación Razón
Número de estudiantes Discreta Se obtiene mediante conteo.
Peso de una mochila Continua Se obtiene mediante medición.
Cantidad de mascotas Discreta Se cuentan las mascotas.
Temperatura de una habitación Continua Puede tomar muchos valores decimales.

Ejercicios

1. Número de alumnos matriculados en una sección.
2. Altura de un edificio.
3. Cantidad de goles anotados por un equipo en un torneo.
4. Tiempo que tarda una persona en recorrer un kilómetro.
5. Cantidad de páginas de un libro.

Respuestas

  1. Discreta. Se obtiene contando estudiantes.
  2. Continua. La altura se mide.
  3. Discreta. Los goles se cuentan.
  4. Continua. El tiempo se mide y puede tener decimales.
  5. Discreta. Las páginas se cuentan.
