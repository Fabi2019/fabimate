Condiciones necesarias y suficientes para definir la composición de dos funciones

Explicación

La composición de funciones consiste en aplicar una función sobre el resultado obtenido por otra función.

Si tenemos:

\[ f:A \rightarrow B \] y \[ g:C \rightarrow D \]

La composición

\[ (f\circ g)(x)=f(g(x)) \]

está definida únicamente cuando cada valor producido por \(g\) pertenece al dominio de \(f\).

Condición necesaria y suficiente

La composición \(f\circ g\) existe si:

\[ \text{Recorrido de } g \subseteq \text{Dominio de } f \]

En otras palabras, todos los valores de salida de \(g\) deben poder entrar en la función \(f\).

Representación gráfica

Primero se evalúa \(g(x)\) y posteriormente ese resultado se utiliza como entrada de \(f\).

Ejemplo Resuelto

Sean:

\[ g(x)=x+1 \] con dominio \[ \mathbb{R} \]

y

\[ f(x)=\sqrt{x} \]

con dominio:

\[ x\ge 0 \]

Para que exista:

\[ (f\circ g)(x) \]

se necesita:

\[ x+1\ge 0 \] \[ x\ge -1 \]

Por tanto, la composición está definida únicamente para \(x\ge -1\).

Ejercicios

Ejercicio 1

Sean:

\[ g(x)=x+3 \] \[ f(x)=\sqrt{x} \]

Determine la condición para que exista:

\[ (f\circ g)(x) \]

Ejercicio 2

Sean:

\[ g(x)=x^2 \] \[ f(x)=\frac{1}{x} \]

¿Para cuáles valores de \(x\) existe:

\[ (f\circ g)(x) \]

?

Ejercicio 3

Sean:

\[ g(x)=2x-5 \] \[ f(x)=\sqrt{x} \]

Determine el conjunto de valores permitidos para \(x\).

Ejercicio 4

Una empresa registra la producción mediante:

\[ g(x)=x+100 \]

y luego calcula el costo:

\[ f(x)=0.5x \]

¿La composición está definida para todos los números reales?

Ejercicio 5

Sean:

\[ g(x)=\sqrt{x} \] \[ f(x)=\ln(x) \]

Determine las condiciones para que exista:

\[ (f\circ g)(x) \]

Respuestas

Ejercicio 1

\[ x+3\ge0 \] \[ x\ge -3 \]

Ejercicio 2

Se requiere: \[ x^2\neq0 \] Por tanto: \[ x\neq0 \]

Ejercicio 3

\[ 2x-5\ge0 \] \[ 2x\ge5 \] \[ x\ge2.5 \]

Ejercicio 4

Sí. Las funciones lineales presentadas están definidas para todos los números reales, por lo que la composición también está definida para todos los reales.

Ejercicio 5

Para la raíz cuadrada: \[ x\ge0 \] Para el logaritmo: \[ \sqrt{x}>0 \] Entonces: \[ x>0 \]
