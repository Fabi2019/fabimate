3.6 Efectuar división de polinomios

Explicación

La división de polinomios es un procedimiento algebraico que permite dividir un polinomio llamado dividendo entre otro polinomio llamado divisor. El resultado se expresa mediante un cociente y, en algunos casos, un residuo.

La relación fundamental de la división es:

\[ \text{Dividendo}=(\text{Divisor})\cdot(\text{Cociente})+\text{Residuo} \]

Cuando el residuo es cero, la división es exacta. Cuando el residuo no es cero, el resultado puede escribirse así:

\[ \frac{\text{Dividendo}}{\text{Divisor}} = \text{Cociente} + \frac{\text{Residuo}}{\text{Divisor}} \]
Procedimiento para dividir polinomios:
  1. Ordenar el dividendo y el divisor de mayor a menor exponente.
  2. Dividir el primer término del dividendo entre el primer término del divisor.
  3. Escribir ese resultado como primer término del cociente.
  4. Multiplicar ese término por todo el divisor.
  5. Restar el resultado al dividendo.
  6. Bajar el siguiente término, si lo hay.
  7. Repetir el proceso hasta que el grado del residuo sea menor que el grado del divisor.
  8. Comprobar usando: dividendo igual a divisor por cociente más residuo.

Ejemplo resuelto

Efectuar la división:

\[ (2x^3+3x^2-11x-6)\div(x+3) \]

Paso 1. Dividir el primer término del dividendo entre el primer término del divisor:

\[ \frac{2x^3}{x}=2x^2 \]

Paso 2. Multiplicar:

\[ 2x^2\cdot(x+3)=2x^3+6x^2 \]

Paso 3. Restar:

\[ (2x^3+3x^2)-(2x^3+6x^2)=-3x^2 \]

Ahora bajamos el término \(-11x\):

\[ -3x^2-11x \]

Paso 4. Dividir:

\[ \frac{-3x^2}{x}=-3x \]

Paso 5. Multiplicar:

\[ -3x\cdot(x+3)=-3x^2-9x \]

Paso 6. Restar:

\[ (-3x^2-11x)-(-3x^2-9x)=-2x \]

Ahora bajamos el término \(-6\):

\[ -2x-6 \]

Paso 7. Dividir:

\[ \frac{-2x}{x}=-2 \]

Paso 8. Multiplicar:

\[ -2\cdot(x+3)=-2x-6 \]

Paso 9. Restar:

\[ (-2x-6)-(-2x-6)=0 \]

Por lo tanto, el cociente es:

\[ \boxed{2x^2-3x-2} \]

y el residuo es:

\[ \boxed{0} \]

Entonces:

\[ \boxed{ (2x^3+3x^2-11x-6)\div(x+3)=2x^2-3x-2 } \]

Ejercicios

1. Efectuar la división: \[ (x^2+7x+10)\div(x+5) \]
2. Efectuar la división: \[ (x^2-4x-12)\div(x-6) \]
3. Efectuar la división: \[ (2x^2+7x+3)\div(x+3) \]
4. Efectuar la división: \[ (x^3+2x^2-5x-6)\div(x+3) \]
5. Efectuar la división: \[ (3x^3-2x^2+4x-7)\div(x-1) \]

Respuestas

1. \[ (x^2+7x+10)\div(x+5)=x+2 \] Residuo: \[ 0 \]
2. \[ (x^2-4x-12)\div(x-6)=x+2 \] Residuo: \[ 0 \]
3. \[ (2x^2+7x+3)\div(x+3)=2x+1 \] Residuo: \[ 0 \]
4. \[ (x^3+2x^2-5x-6)\div(x+3)=x^2-x-2 \] Residuo: \[ 0 \]
5. \[ (3x^3-2x^2+4x-7)\div(x-1) = 3x^2+x+5-\frac{2}{x-1} \] Cociente: \[ 3x^2+x+5 \] Residuo: \[ -2 \]
