2.A6.5. Determina la función lineal, cuadrática, raíz cuadrada, exponencial o logarítmica que sirva de modelo en diversos contextos

Explicación

En la modelación matemática es importante identificar el tipo de función que mejor describe un fenómeno real. Cada tipo de función presenta características particulares que permiten representar situaciones específicas.

Función Modelo General Contexto Típico
Lineal $$y=mx+b$$ Costos, salarios, distancia a velocidad constante.
Cuadrática $$y=ax^2+bx+c$$ Trayectorias de objetos, áreas y máximos o mínimos.
Raíz cuadrada $$y=\sqrt{x}$$ Crecimientos que disminuyen progresivamente.
Exponencial $$y=a\cdot b^x$$ Crecimiento poblacional, inversiones y bacterias.
Logarítmica $$y=\log(x)$$ pH, decibelios y escala Richter.

¿Cómo identificar el modelo?

  • Si la variación es constante → función lineal.
  • Si la gráfica forma una parábola → función cuadrática.
  • Si el crecimiento es cada vez más lento → función raíz cuadrada.
  • Si el crecimiento ocurre por multiplicaciones repetidas → función exponencial.
  • Si aparecen escalas como pH, Richter o decibelios → función logarítmica.

Ejemplo resuelto

Una inversión de ₡100000 aumenta un 5% cada año.

Modelo:

$$ M(t)=100000\cdot(1.05)^t $$

Como el crecimiento se produce multiplicando por el mismo factor cada año, corresponde a una:

Función exponencial.

Respuesta: El modelo adecuado es una función exponencial.

Ejercicios

1. El costo de un taxi se calcula mediante una tarifa fija de ₡800 más ₡500 por kilómetro recorrido.

¿Qué tipo de función modela la situación?

2. La trayectoria de una pelota lanzada al aire se representa mediante una parábola.

¿Qué tipo de función modela la situación?

3. Una colonia de bacterias se duplica cada hora.

¿Qué tipo de función modela la situación?

4. El pH de una sustancia se calcula mediante:

$$ pH=-\log([H^+]) $$

¿Qué tipo de función modela la situación?

5. La distancia recorrida por una persona aumenta cada vez más lentamente siguiendo un comportamiento semejante a:

$$ y=\sqrt{x} $$

¿Qué tipo de función modela la situación?

Respuestas

1. Función lineal.

2. Función cuadrática.

3. Función exponencial.

4. Función logarítmica.

5. Función raíz cuadrada.
